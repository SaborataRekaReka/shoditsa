# Библиотека свояка

Локальная рабочая библиотека с неизменяемыми исходниками, редакторскими версиями,
поиском, сборкой тематических паков и журналом реальных игр.

Редакторская политика: [EDITORIAL_POLICY.md](EDITORIAL_POLICY.md). Мат, пошлость,
18+, странности и абсурд сохраняются. По умолчанию используется авторский текст.

## Запуск

Из корня проекта, Python 3.13:

```powershell
python -m pip install -r scripts/svoyak/requirements-semantic.txt
python -X utf8 scripts/svoyak/manage.py serve
```

- **Проверка всей редакции:** http://127.0.0.1:5188/review.html
- Библиотека: http://127.0.0.1:5188/library.html?v=4
- Редактор и сборщик: http://127.0.0.1:5188/workbench.html
- Готовый взрослый пример: http://127.0.0.1:5188/workbench.html?session=32b636a7-9cbe-4082-afe2-45c254ca83fd#builder

Сервер слушает только loopback. Для записи интерфейс использует одноразовый для
запуска токен и проверку Origin. Это локальный редактор ведущего; публичный сервер
и многопользовательская авторизация в эту реализацию не входят.

## Что сохранено

`archive/local/svoyak-library/` игнорируется Git:

- `packs/*.siq`, `sources.json` — 9 скачанных паков и контрольные суммы.
- `library.sqlite3` — пересоздаваемый индекс: 1 313 вопросов, оригиналы XML,
  раунды, темы, ответы, медиа, категории, FTS5 и нейронные векторы.
- `editorial.sqlite3` — устойчивое состояние: версии правок, проверки, источники,
  журнал действий, условия использования, компании, сохранённые паки, показанные
  вопросы и результаты игроков. Схема мигрируется отдельно (`user_version=2`).
- `models/` — локальная, заранее обученная мультиязычная модель поиска. Здесь не
  выполняется обучение весов и не отправляются вопросы во внешний AI API.
- `research-cache/` — снимки справочных материалов с URL, датой и SHA256.
- `quality-report.json`, `media-audit.json`, `research-disposition.jsonl` — проверки
  и явный статус каждого вопроса. «Не исследован» не означает «верен».
- `backups/` — архивы, `restore-test.json` — результат восстановления.

Утверждение связано с хешем исходного вопроса и разобранного содержания. Изменение
источника снимает допуск, старая правка остаётся в истории. Изменение одобренной
формулировки требует черновика и повторной проверки. Обычное сохранение той же
формулировки не сбрасывает допуск и игровую статистику.

## Редактура и игровой зачёт

Жанр и основание зачёта задаются отдельно. Смешной фактический вопрос всё равно
требует источника. Для антизагадки, абсурда, каламбура или ироничного пересказа
проверяются авторская задумка и допустимый ответ; буквальная правдивость гиперболы
не требуется. В отчёте фактчекинга такие случаи имеют `not_applicable`, а не
ложную отметку о научной проверке.

Редактор видит оригинал, все исходные медиа, игровую версию, допустимые ответы,
пояснение ведущему, доказательства и историю. У одобрения восемь проверок. Технические
ошибки медиа блокируют версию с этими файлами. У самостоятельной текстовой версии
дополнительные картинки ответа не включаются в игру, но остаются в исходнике.

Стартовое ядро — **200 текстовых игровых версий**: 129 с фактическими источниками
и 71 с проверенным игровым зачётом. Включены абсурд, чёрный юмор, двусмысленности
и пародийные пересказы. У 65 специально отобранных шуточных вопросов формулировка
совпадает с исходной дословно. Для остальных **1 113 карточек** подготовлена отдельная редакторская версия со статусом «Требует проверки». Ни одна из них не одобрена автоматически.

Ручной пакет решений: `qa/svoyak-pilot-2026-10-21/starter-reviewed.json`. Он привязан
к точной версии источников. `curate_starter.py --apply` применяет эту явную подборку
один раз; существующие редакторские правки не перезаписывает. Обычный импорт её
автоматически не переутверждает.

## Сборка и игры

Компания сохраняет интересы, жанры, уровень, возраст, время, число раундов и тем.
Для взрослой компании по умолчанию доступно 18+. В каждой теме ровно 5 вопросов;
неполные темы не выдаются за готовый пак. Учитываются редакторская сложность,
разнообразие, ответы, дубли и показанные этой компании вопросы. Seed сохраняется,
поэтому подбор воспроизводим при том же состоянии базы и истории.

Сохранённый пак фиксирует формулировки и источники. Изменённый или снятый с допуска
вопрос нельзя незаметно экспортировать из старой подборки. Экспорт SIQ5 проверяется
по приложенной XSD. Реальный импорт в приложение SIGame отдельно не тестировался.

Открытие вопроса в режиме ведущего записывает показ; просмотр редакторской карточки
не расходует вопрос. Результаты вводятся по игрокам/командам: верно/неверно, время,
спор, интерес. Повторный запрос не удваивает статистику. Калибровка привязана к
версии содержания; до 20 ответов из 3 компаний и при доле споров от 10% сложность
остаётся предварительной. Показывается интервал неопределённости решаемости.

## Обслуживание

```powershell
python -X utf8 scripts/svoyak/manage.py check
python -X utf8 scripts/svoyak/manage.py media
python -X utf8 scripts/svoyak/manage.py factcheck
python -X utf8 scripts/svoyak/manage.py backup --models
python -X utf8 scripts/svoyak/manage.py restore-test --archive "путь-к-копии.zip"
python -X utf8 scripts/svoyak/manage.py restore --archive "путь-к-копии.zip" --destination "новая-папка"
```

`check` охватывает все вопросы и сверяет архивы, целостность SQLite, связи и индекс.
Проверка структуры не является проверкой всех фактов. Команда `factcheck` использует
репозиторный read-only runbook для всего фонда, без платного AI запуска. Ручные
решения и явно нерешённые задачи находятся в `research-disposition.jsonl`.

Проверка медиа ограничивает сетевые запросы и не обращается к частным адресам.
Внешние ссылки проверяются на доступность и сохраняются. Скачанные файлы доступны
локально; включение в готовые пакеты требует принятия медиа. FFprobe проверяет
аудио/видеоконтейнеры. Смысл, громкость, границы фрагмента и отсутствие спойлера
проверяются отдельно в медиаредакторе.

Полная копия `--models` включает исходники, обе SQLite, справочные снимки, модель
и код локального приложения. Восстановление разрешено только в новую папку,
проверяет каждый SHA256 и SQLite. Внутри получается `project/` с обычной структурой
проекта. Для полной копии тест запускает восстановленный Python runtime без сети.
Рабочая база при этом не перезаписывается. Зависимости Python устанавливаются по
requirements; Node factcheck pipeline требует исходный репозиторий и его зависимости.

Для повторного импорта:

```powershell
python -X utf8 scripts/svoyak/manage.py build
# либо sync для повторной синхронизации скачанных источников и модели
```

После пересборки перезапустите локальный сервер, чтобы обновить векторный индекс в
памяти. `editorial.sqlite3` не пересоздаётся. Не редактируйте `library.sqlite3` вручную.

## Границы готовности

Условия публичного повторного использования всех 9 исходных паков пока неизвестны.
В базе есть основания/ссылки для будущего подтверждения, но разрешения авторов не
придуманы. Публичный экспорт блокируется до заполнения соответствующего основания.
Локальный экспорт явно помечен своим назначением и содержит provenance.

Реальных результатов игр пока нет. Тестовые игроки и фиктивные разрешения существуют
только в отдельных временных тестовых базах. Полная фактическая/медийная проверка
1 313 вопросов не заявляется завершённой; одобренное ядро доступно для работы. Все оставшиеся карточки представлены в очереди проверки редакции.

## Полный редакторский проход и ручная проверка

`review.html` — основной интерфейс владельца: оригинал и версия рядом, видимые ответы,
фильтры по паку/теме/жанру/замечаниям, сравнение текста, локальные и внешние медиа,
заметки и история. Ctrl+S сохраняет; Ctrl+Enter принимает текст и открывает следующий
вопрос. Просмотр не отмечает вопрос сыгранным. Можно вернуть исходный текст и
скачать JSON всех 1 313 карточек. JSON содержит данные редакции, медиа — в SIQ и копиях.

Для 1 113 карточек из 216 тем записаны явные решения в `edition_specs.py`;
полный снимок предложений — `qa/svoyak-pilot-2026-10-21/full-edition-reviewed.json`.
Уже хорошие формулировки оставлены, к пустым медиа-карточкам добавлено краткое
условие, громоздкие вопросы сокращены, ошибки и неоднозначности вынесены в заметки.
Факты и смысл аудио/видео/изображений этим проходом **не утверждены**. Все
829 заданий, зависящих от медиа, помечены для просмотра; внешние ссылки и
служебные события видны отдельно. SIQ4 `voice` теперь отображается как аудио.

Решения «Текст принят», «На доработку», «Редакция отклонена» сохраняются
в `edition_items` и аудите. Они не подменяют восемь проверок допуска к игре.
Изменение версии после принятия возвращает решение к ожиданию проверки;
конкурирующие изменения из второй вкладки получают конфликт вместо потери данных.
Исходный текст, первая предложенная редакция и история остаются доступны.

Импорт снимка атомарен, привязан к исходным хешам и не переписывает существующие
ручные правки. Перед импортом сохраняется SQLite-снимок редакторского состояния.

```powershell
python -X utf8 scripts/svoyak/full_edition.py          # пересоздать предложение
python -X utf8 scripts/svoyak/full_edition.py --apply  # применить только отсутствующие
node qa/svoyak-pilot-2026-10-21/check-full-edition.mjs
```

## Медиаредакция

Открыть: http://127.0.0.1:5188/media.html. Здесь все 930 карточек с 1 325 ссылками:
оригинал и предложенная версия рядом, вопрос и ключ, контрольные кадры, waveform,
измерения, OCR/ASR, редакторские заметки и ссылки на подтверждающие источники.
Медиа ответа изначально свёрнуты. Для координатных ответов показана авторская точка.
Фильтры выделяют недоступные файлы, спойлеры, громкость, нечитаемость и спорный зачёт.

Из 324 внешних URL скачаны 129; остальные 195 возвращают HTTP 404 из удалённого
бакета openquiz. Все доступные 1 116 уникальных исходных файлов прошли декодирование:
914 изображений и 202 аудио/видео. Ошибок декодирования не обнаружено. Просмотрены
928 ссылок на изображения и шесть контрольных кадров каждого из 83 видео. Для 201
записи со звуком рассчитаны громкость/паузы и получена машинная расшифровка; для
119 аудиовопросов прочитаны фрагменты ASR. Полное прослушивание, покадровый просмотр
всех роликов и подтверждение всех произведений/авторских ключей **не выполнены**.
Неопределённости явно сохранены; распознавание лиц реальных людей не выполнялось.

Подготовлены 145 отдельных предложений: 127 для громкости/пауз, 17 копий без названий
в метаданных и одна маска над подписью с ответом. Ни одно предложение не выбрано
автоматически. Метаданные удалены без перекодирования; проверка PCM у 16 копий
совпала полностью, у одной сохранилось исходное PCM с 39 дополнительными конечными
стереосэмплами (около 1,2 мс). Подробности — `media/metadata-copy-checks.json`.
Размытие, переворот кадра, шутки и 18+ намеренно не «исправлялись».
Два бесполезных предложения нормализации цифровой тишины сняты; два коротких ролика
пересчитаны линейным усилением до −17,71 и −18,00 LUFS. Отчёт контрольных измерений —
`media/renditions-postcheck.json`. Тишина в двух исходниках явно отмечена.

Выбери файл/версию, просмотри или прослушай его, заполни четыре проверки и нажми
«Принять медиа» либо оставь заметку/отправь на доработку. Выбор другой версии,
изменение файла или текста снимает прежнее принятие. Изменения сохраняются в
`editorial.sqlite3` (схема 3) с историей и защитой от конфликтов; исходные SIQ не
перезаписываются. Несохранённые заметки защищены при переходе между вопросами.

Воспроизведение файлов не обращается к внешним хостам. Чтение и перемотка идут из
локального кеша с HTTP Range. Внешняя ссылка открывается только по нажатию.

```powershell
python -X utf8 scripts/svoyak/media_pipeline.py acquire
python -X utf8 scripts/svoyak/media_pipeline.py analyze
python -X utf8 scripts/svoyak/media_pipeline.py metadata
node scripts/svoyak/media_ocr.mjs "путь-к-node_modules-с-tesseract.js"
python -X utf8 scripts/svoyak/media_pipeline.py transcribe
python -X utf8 scripts/svoyak/media_pass.py
python -X utf8 scripts/svoyak/media_pass.py variants
python -X utf8 scripts/svoyak/media_pass.py factcheck
python -X utf8 scripts/svoyak/media_report.py
node qa/svoyak-pilot-2026-10-21/check-media.mjs
```

Дополнительно нужны FFmpeg/FFprobe 8.1.2 в PATH и `requirements-media.txt`. ASR
использует уже скачанную `Systran/faster-whisper-base`, без сети и API. OCR-модели
eng/rus закреплены хешами в `media/ocr-models/manifest.json`; Node tesseract.js 7.0.0.
Перенос кеша позволяет смотреть результаты без повторного OCR/ASR. Источники и
варианты — `media/objects/`, измерения/кадры — `media/analysis/`, полный журнал
редакции — `media/disposition.jsonl`, итог — `media/review-report.json`. Команда
`factcheck` закрепляет снимок входных данных и отдельное явное unresolved-решение
для каждой из 930 карточек; AI не запускается. Это очередь ручной проверки, а не
утверждение, что все факты прошли проверку.

Браузерные проверки используют отдельную копию базы: принятие, отмена, смена версии,
сброс прежнего одобрения, сохранение перед переходом, 404, Range, декодирование видео,
координатный ответ и экран 390 px. Фиктивные решения в рабочую базу не записываются.

## Смысловой проход и очередь спорного

`media.html?filter=semantic_review` — отдельная очередь владельца. Карточки
отсортированы по приоритету: расхождения, раскрытый ответ / пустое задание, затем
недоступное содержимое, звук, атрибуция, неоднозначный зачёт и источники. Фильтр
причины и краткое заключение показывают, что именно требуется проверить.
`media.html?filter=semantic_consistent` показывает согласованные визуальные связи.
Это заключение о связи медиа с ключом, а не фактчекинг каждого утверждения текста.

Полностью прочитаны контексты 202 исходных AV-файлов и полные ASR-результаты
(119 аудио, 83 видео; у одного видео нет звуковой дорожки). Для 26 коротких русских
речевых записей дополнительно выполнен и сопоставлен локальный small-ASR. Повторная
расшифровка показана в карточке. Оба ASR могут ошибаться; совпадение моделей не
является независимым источником. Полного прослушивания нет, все неатрибутированные
музыкальные и неречевые ключи остаются в очереди. Видео просмотрены по контрольным
кадрам, быстрые промежуточные события не считаются проверенными.

В снимке прохода 324 карточки имеют согласованную связь медиа с ключом, 606 вынесены
на проверку: 2 расхождения, 514 неоднозначных и 90 карточек с недоступными файлами.
Причины пересекаются. Все 1 325 ссылок получили явное заключение. Сняты лишние
неопределённости у точек на карте, части ребусов, предметных микрофотографий и
цветовых образцов с текстовыми подсказками. У музыкальных mashup проверяется
полнота ключа, у ответных постеров — только иллюстрируемое произведение: постер не
подтверждает музыку или эпизод. Личности реальных людей по фото/голосу не выводились.

```powershell
python -X utf8 scripts/svoyak/media_semantics.py
```

Команда сохраняет заключения в `media_assessments`, закрепляет входные хеши и
создаёт read-only factcheck-run `fields=media, research=all, ai=never`: все 930 задач
получают pass только в ограниченной области связи медиа либо явный uncertain.
Итоги — `media/semantic-audit/latest.json`; полный снимок —
`qa/svoyak-pilot-2026-10-21/media-semantic-review.json`, спорное —
`media-semantic-queue.json`. Неизвестный набор наблюдений или изменённый контекст
не может незаметно унаследовать согласование: повторный запуск остановится на
несовпадении закреплённых хешей. В интерфейсе смена текста/файла возвращает смысловое
заключение в очередь. Существующие ручные решения, история игр и исходники не
переписываются. Явное актуальное принятие владельцем закрывает соответствующую
проверку в живой очереди, сохраняя прежнее заключение в данных.

без медиа, затем 307 с предварительно согласованной визуальной связью. Допущены
137 и 292 соответственно: 429 новых, всего 629 готовых в локальной библиотеке.
Оставшиеся 63 текстовые и 15 с медиа находятся в отдельной очереди владельца.
Восьми из них нужен пока не поддержанный экспортёром выбор точки на карте.
606 остальных карточек с нерешёнными медиа не входят в этот проход.

Откройте `http://127.0.0.1:5188/admission.html`: фильтры готового и спорного,
оригинал рядом с редакцией, ключи и варианты зачёта, иллюстрации в своих фазах,
причины решения, источники и переходы к редактированию текста и медиадопусков.
`review.html?batch=507&view=owner` ограничивает редактор этой очередью.
Просмотр не создаёт игровых событий. Изменение текста или медиаверсии снимает
зависимые допуски; отправка принятого текста на доработку также снимает готовность.

Каждая карточка получила явное решение. Вопросы на узнавание изображения отмечены
как наблюдение по первичному медиа; это отличается от проверки внешних утверждений
по источникам. Шутки и абсурд имеют игровой принцип зачёта, сохранены мат и 18+.
Решения подписаны Codex, не выданы за прослушивание человеком. В данной принятой
подборке только изображения и один немой ответный ролик; музыкальные и речевые
неопределённости прежней очереди не получили автоматического допуска.

Закреплённые исходные данные и версии решений находятся в
`archive/local/svoyak-library/readiness-507/`. Первоначальные пакеты 200/307,
два последующих решения и прежние аудиты сохраняются отдельно. Последний повторный

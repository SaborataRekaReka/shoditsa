# Работа с библиотекой

Перед изменением формулировок, фильтров и правил редакторского одобрения прочитайте
[EDITORIAL_POLICY.md](EDITORIAL_POLICY.md). Пользователь явно просит сохранять
пошлость, 18+, мат, странности, абсурд и юмор. Не стерилизуйте исходники.

Исходные SIQ и source index неизменяемы со стороны редактора. Правки, источники,
аудит, предпочтения и результаты игр сохраняются в отдельном `editorial.sqlite3`.
Импорт не должен удалять это состояние. Изменение исходника снимает прежнее одобрение.

Не выдавайте игровой зачёт шутки за фактчекинг. Не придумывайте результаты игр,
разрешения авторов и статистическую калибровку. Тесты используют отдельную временную
базу редакторских данных; фиктивные ответы не записываются в рабочую статистику.

Payload — `.tmp/server-journeys-validation/result.json`, полученный ранее SELECT-only запросом к production. SHA-256 источника зафиксирован в JSON доказательстве. Аутентификация не обходилась: это самостоятельная отрисовка компонента, а не вход в админку. API и внешние запросы блокировались. UI-изменений в процессе проверки не потребовалось.

Проверены четыре комбинации: ширина 1280/390 px, окна 14/31 день. Во всех случаях document и дочерние блоки не выходят по горизонтали, ошибок страницы нет. Файлы: `admin-server-journey-browser-check.json`, воспроизводимый одноразовый `.mjs` и четыре `admin-server-journey-*.png`. Fixture-сервер 5197 принадлежит координатору и не останавливался. На скриншотах может присутствовать служебный бейдж fixture «Просмотр состояния»; он не относится к новому компоненту. Проверка не подтверждает боевую авторизацию, доступность production endpoint или подключение продовых шрифтов.

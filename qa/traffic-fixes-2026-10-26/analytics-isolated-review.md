# Изолированная проверка аналитики

26.10.2026. Код изучен независимо от автора. Конкретных блокеров в новой семантике page_view, согласия, route identity, версии клиента и обработке обещаний View Transition не найдено. Код не редактировался во время review.

Одноразовый `analytics-isolated.mjs` запускал новый headless Chromium с отдельным context, без сохранённого профиля, аккаунта, cookies и production URL. Обычный Vite работал на `127.0.0.1:5198`, proxy направлен только на локальный fixture `5197`, `VITE_LOCAL_REDESIGN`, `VITE_REFERENCE_API`, `VITE_PUBLIC_THEME` выключены. API client-events перехватывались и сохранялись локально, любые остальные API writes блокировались. Все внешние запросы запрещены; зафиксированы попытки загрузить только Google Fonts и Metrika tag, они прерваны. Это не подтверждение внешней доставки в Метрику.

Наблюдения из `analytics-isolated.json`:

- До решения о согласии: 0 отправленных page_view и 0 hit Метрики.
- После принятия: ровно 1 page_view и 1 hit; appVersion совпадает с искусственно установленным HTML SHA `aaaa...`, а не `dev`.
- Повторное объявление того же маршрута и обновление уже принятого согласия: 0 новых page_view/hit.
- SPA-переход в «Животные»: ровно 1 новый page_view. Добавление token/UTM/hash к тому же экрану — 0 новых.
- Back на прежний экран и Forward: по одному view; промежуточный возврат по отличающейся только query/hash записи не создаёт дополнительный view.
- Отказ через реальный footer cookie: следующие маршруты дают 0 hit Метрики, necessary event имеет `analytics_consent=rejected`, acquisition отсутствует.
- Повторное разрешение через footer: ровно один новый consented view и один hit.
- Всего 9 page_view и 9 различных eventId. `pageerror` отсутствуют. Production-запросов и записей нет.

Ограничения: фиктивная session-навигация перенаправилась в `/play/movie`, поэтому это **не** browser-подтверждение приватного реального session route. Функция canonical отдельно выполнена в браузере для `/sessions/private-id`, Svoyak join/room/result и вернула обезличенные пути; тестовые query-токен и session ID отсутствуют в экспортированных событиях/ym calls. Реальный серверный запуск игры, авторизация и платежи не проверялись. Использован `reducedMotion=reduce`: native анимация и её отмена проверены код-ревью, а не этим browser-прогоном.

После проверки браузер закрыт и временный Vite 5198 остановлен. Скрипт, JSON и screenshot сохранены рядом. Это одноразовая браузерная сверка на fixtures, без тестовых suites и локального Docker.

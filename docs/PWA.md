# PWA

Сайт устанавливается как «Сходится!» и запускается в отдельном окне со стартовой страницей `/`. Идентификатор приложения и область действия: `/`. Manifest подключён также ко всем статическим публичным страницам.

В поддерживающих установку Chromium-браузерах пункт «Установить приложение» появляется в меню аккаунта после события `beforeinstallprompt`. Он вызывает системный диалог только по нажатию. На iPhone и iPad этот пункт открывает инструкцию по добавлению через меню «Поделиться». В установленном приложении пункт скрыт. В режиме Yandex Games и во фреймах регистрация service worker отключена.

Игры требуют подключения к серверу. Service worker сохраняет только `/offline.html` и три иконки из `/pwa/`. Запросы API, авторизация, оплаты, игровые данные, результаты и HTML страниц не сохраняются. При недоступной сети переход на страницу показывает автономный экран с повторной загрузкой. Ответы HTTP, включая 404 и 500, сохраняют статус и содержимое сервера.

Новый service worker ожидает закрытия предыдущих окон. Принудительной активации и перезагрузки из PWA нет. Проверка обновления выполняется при возвращении в приложение и восстановлении сети, не чаще раза в минуту. Существующая проверка версии сайта продолжает откладывать перезагрузку активных игровых попыток.

При изменении автономного экрана или иконок нужно изменить версию `CACHE` в `public/sw.js`. При активации удаляются только старые кэши с префиксом `shoditsa-pwa-`. `/sw.js` отдаётся с `application/javascript`, `Cache-Control: no-cache, no-store, must-revalidate` и `Service-Worker-Allowed: /`; manifest — с `application/manifest+json` и `no-cache`.

`npm run build` включает проверку manifest, размеров обычных и maskable-иконок, автономности offline-страницы и наличия service worker. Тесты `apps/web/src/app/pwa.test.ts` проверяют границы сети и кэша. Браузерные проверки релиза и результаты хранятся в `qa/pwa-2026-10-24/`.

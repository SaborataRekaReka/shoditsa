# Единый локальный стенд с настоящим API

Текущий интерфейс берётся из `C:/projects/dev/seans_starter_pack`, API и данные — из `https://shoditsa.ru`. Один порт: **5180**. Фикстуры аккаунта, игр и комнат в обычном запуске отключены. Действия авторизованного пользователя изменяют его настоящий прогресс и комнаты.

## Основной сценарий: встроенный браузер и аннотации

Использовать **http://127.0.0.1:5180/** во встроенном браузере Codex, запуск — `npm run preview:review`. Пользователь отмечает элементы и присылает комментарии прямо из этой вкладки. Этот режим восстановлен 22 октября после проверки отдельного Chrome; `/__qa/status` подтверждает `apiForwarding: true`, `fixtures: false`, `yandex: false`.

Не открывать основной домен для проверки локальных правок: во встроенном браузере `https://shoditsa.ru` показывает развёрнутый сайт. Отдельный Chrome с подменой адреса не поддерживает этот рабочий процесс аннотаций и не переносит свою сессию во встроенный браузер. На localhost пока работает вход по email и паролю; полноценный Яндекс-вход именно во встроенном браузере остаётся нерешённым. Следующий HTTPS-профиль — только дополнительный инструмент, он не должен заменять основной просмотр без явного запроса пользователя.

## Вход через Яндекс

```powershell
npm run preview:review:yandex
```

При Node ниже 24:

```powershell
npm exec --yes --package=node@24.14.1 -- npm run preview:review:yandex
```

После запуска сервера открыть выделенный браузер второй командой из корня проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/preview-reference-yandex.ps1 -OpenBrowserOnly
```

В этом Chrome `https://shoditsa.ru` направлен на локальный HTTPS-сервер 5180. На странице показано «Локальный дизайн · настоящий аккаунт». Обычный браузер по тому же домену показывает основной сайт. HTTP-адрес `http://127.0.0.1:5180` в этом профиле не используется. Callback, state и cookies Яндекса проходят штатным путём. Существующий доверенный сертификат действует до 14 ноября 2026; запуск проверяет доверие, не устанавливает его и не отключает TLS. Подробнее: [REFERENCE_YANDEX_PREVIEW.md](REFERENCE_YANDEX_PREVIEW.md).

## Вход по email без выделенного Chrome

После остановки HTTPS-профиля можно запустить `npm run preview:review` и открыть `http://127.0.0.1:5180/`. Он подключён к тому же реальному API, но OAuth callback и ссылки регистрации/сброса требуют основного домена. Эти два запуска не должны работать одновременно на 5180.

## Отдельные фикстуры

`npm run preview:fixtures` — явно выбранный автономный просмотр состояний. Он тоже занимает 5180, поэтому основной стенд перед ним нужно остановить. Только в этом режиме существует `/__qa`. Фикстуры не подтверждают работу настоящего сервера. Сохранённые примеры комнат находятся в `.tmp/local-review/rooms.json` и не импортируются в production.

«Своя игра» использует тот же production API `/api/v1/svoyak`, что и основной
сайт. Локальный Vite middleware и SQLite-комнаты отключены. Для игры не нужен
редактор на 5188. Создателю нужен реальный Клуб, приглашённым — нет.

`/__qa/status` в подключённом режиме возвращает `apiForwarding: true`, `fixtures: false`, реальную цель API и используемый профиль. API и media проксируются с проверкой TLS. Admin и файлы ответов закрыты. Локальные аналитические события не отправляются в production. Для бесплатных игр автоматически создаётся настоящая гостевая сессия, как на основном сайте. Для создания клубных комнат нужен вход в аккаунт с активным Клубом. Гость может присоединиться по приглашению без оплаты.

## Лобби

Порядок: выбрать режим и настройки → создать комнату → пригласить участников → начать. После создания показаны краткие правила, участники, ссылка приглашения и запуск; повторная полная форма скрыта под «Изменить». Участники доступны в основной колонке и на телефоне. При существующей комнате лобби предлагает вернуться в неё; выход/закрытие перед новой комнатой требуют отдельного явного действия. Настройки черновика сохраняются в сессии браузера. Запуск одному обозначен явно; Захват ждёт двух подключённых игроков.

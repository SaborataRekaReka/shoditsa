# Угадай слово по ассоциациям

## Паспорт и объём

- modeId: `word`, engine: `semantic_word`, library: `words`.
- Русское название: «Слово по смыслу». Основной запрос: «Угадай слово по ассоциациям».
- Серверная ежедневная партия, архив по общим правилам доступа, сохранение в аккаунте и после перезагрузки, неограниченные попытки, подсказки, сдача, результат и шаринг.
- Ответы: 180 редакционно отобранных русских существительных с равными квотами по девяти темам. Точный словарь попыток фиксируется манифестом после проверки покрытия.
- Самостоятельный семантический движок необходим: ввод свободного слова и один ранг по смыслу не являются сравнением карточек по 6–11 признакам. Механика не притворяется `catalog_guess`.
- Переиспользуются манифест режимов, существующий router, оболочка, `game_sessions`, daily challenges, контентные ревизии, авторизация, статистика и вознаграждение завершения.
- Из runbook применяются закрытость ответа, data-first, release-content и active revision, matching web/API/worker SHA, тесты и production browser gate. Фотография карточки и признаки сравнения не применимы к свободному семантическому слову.
- Ранги вычислены локально заранее. Runtime читает закрытый неизменяемый пакет по SHA256; браузер не получает словарь ответов, векторы или таблицу рангов.
- День меняется в 00:00 Europe/Moscow. Не выдавать будущие или до-релизные даты. Попытки и подсказки идемпотентны, доступ к чужой сессии закрыт.
- Подсказка добавляет ещё не использованное слово ближе к ответу. Сам ответ подсказкой не отдаётся. После сдачи он раскрывается как terminal result.
- Полноценный отдельный renderer переиспользует общий shell и примитивы. Состояние hosted-игры хранится только на сервере.

## Источники и этапы

`scripts/semantic/fetch.py`: возобновляемая загрузка официальных Navec и fastText с фиксацией URL, размеров и локальных SHA256. Большие исходники находятся в игнорируемом `archive/local/semantic-models` и не входят в web/API image.

`scripts/semantic/build.py`: lexicon → projected Navec/fastText → сравнение на общем словаре → редакционный review → закрытый versioned pack и библиотека. Частоты wordfreq служат только фильтром обычных слов, не поисковой частотностью и не современной статистикой языка. Ранги имеют смысл только в рамках конкретной версии словаря.

Проверочные пары — собственные редакционные примеры. Они не являются стандартизированным бенчмарком, фактической проверкой или доказательством качества игры для людей. Сохранены исходы обеих моделей и соседние слова для ручного просмотра.

## Gates выпуска

1. Неизменяемый пакет проверен по SHA, размерам, полным перестановкам рангов и self-rank=1. Для всех 180 ответов просмотрены ближайшие слова; неоднозначные или неигровые цели исключены.
2. API migration и интеграционные тесты: изоляция пользователей, нормализация е/ё и словоформ, неизменяемый ответ, daily resume, архив, concurrency/idempotency, подсказки и сдача, единственное начисление награды.
3. Контентная библиотека и закрытый пакет включены в полный API image. Данные подготовлены и активированы до публичного включения.
4. Титул, попытки, пустой/неизвестный/повторный ввод, подсказка, результат, reload и архив проверены в браузере на desktop и 390 px в обеих темах.
5. Matching SHA web/API/worker, новая active revision с положительным count, production smoke и реальная партия.

Исследование спроса от 24 октября не является доказательством будущих переходов. После выпуска технический контроль и завершённые измерительные окна выполняются отдельно; рост не заявляется по одному успешному релизу.

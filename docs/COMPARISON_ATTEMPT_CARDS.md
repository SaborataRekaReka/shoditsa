# Карточки попыток

`apps/web/src/features/game-session/ComparisonAttemptCard.tsx` — общий каркас
для десяти режимов сравнения и спецпоказа K-pop. `ComparisonAttemptCard.css`
владеет рамкой, шапкой, изображением, метаданными, адаптивностью и счётчиками.
Старые правила `.attempt-card` исключают `.comparison-attempt`; они сохранены
для административных превью. Страница не переопределяет внутренние элементы
нового каркаса.

Настройки `ATTEMPT_PRESENTATION` выбирают формат изображения и вид сводки:
`compact` (значок и число), `labels` (с подписями), `bar` (только шкала).
Обложки и фотографии заполняют свой формат; маскоты, гербы и портреты персонажей
показываются целиком. При необходимости конкретная карточка передаёт
`presentation` с переопределением этих настроек.

Игра передаёт `subtitle`, `details`, `metadata` и содержимое `children`.
Для простых метаданных используется `AttemptMetadata`. Особые блоки вроде
систем органов, студий, рангов городов и признаков персонажей остаются у режима.
Шапка не повторяет номер отдельной декоративной плашкой.

`AttemptMatchSummary` получает подсказки попытки и использует существующий
`attemptProgressStats`. Точное совпадение поля и частичное пересечение считаются
отдельно. Отсутствие данных не становится совпадением. Количество сегментов
берётся из числа сравниваемых полей, а не из лимита попыток. Цвета берутся из
`--match-exact-ink` и `--match-partial-ink`; значки и доступное описание сохраняют
смысл без цвета.

В карточку передаётся только отправленная версия игрока. Скрытый ответ не нужен
компоненту. Для уже разрешённого раскрытия ответа используется `isAnswerReveal`.

Живые варианты находятся в `/ui-kit#attempt-cards`: игры, отсутствие картинки,
точные и частичные совпадения, победа и отсутствие данных. После изменения
каркаса проверяются потребители на десктопе и ширине 320 px, в обеих темах.

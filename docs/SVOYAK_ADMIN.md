# Редактор «Своей игры»

Адрес: `/admin/svoyak`, пункт «Своя игра» в административном меню.
Использует штатную проверку роли, UUID и email владельца на каждом API-запросе.
Ответы не доступны через публичный каталог. Записывающие запросы проверяют Origin.

Менеджер показывает все строки текущей production-ревизии, включая снятые
вопросы и вопросы неполных тем, которых нет в каталоге лобби. Это не импорт
непроверенного локального SIQ-архива. Отсутствующие в каталоге лобби пак и интерес
восстанавливаются в редакторе из метаданных самих вопросов.

Поиск работает по формулировке, ответу, вариантам зачёта, теме, паку и ID.
Фильтры: пак, интерес, допуск и наличие медиа. Вопросы можно создавать,
дублировать, переносить между паками, удалять из черновика и снимать с игры.
Паки можно создавать, переименовывать, снимать целиком с игры и удалять пустыми.

Предпросмотр использует `SvoyakQuestionContent`, общий с настоящей комнатой.
Есть вопрос игроку, раскрытый ответ, ключ ведущего и ширина телефона.
Стоимость в превью иллюстративная: сложность × 100. Фактическая стоимость
назначается сборщиком по месту вопроса и раунду.
Медиа показываются по порядку, с ручным запуском аудио/видео. Ошибка загрузки
видна прямо в превью. Файлы до 18 МиБ: JPEG, PNG, WebP, MP3, WAV, OGG, MP4,
WebM. Изображения конвертируются в WebP. Можно добавить HTTPS-ссылку.
Удаление медиа убирает связь с вопросом; файл сохраняется для старых партий.

## Сохранение и публикация

Правки в форме сразу видны в превью. «Сохранить черновик» сохраняет весь
рабочий набор в `app_settings['svoyak.editor.workspace.v1']`. После этого
можно перезагрузить страницу. Несохранённые правки защищены предупреждением
при уходе; до сохранения публикация заблокирована.

«Опубликовать» проверяет возможность собрать стандартную игру из трёх полных
тем с учётом дублей, создаёт новую ревизию и атомарно переключает активную.
Активная ревизия никогда не редактируется напрямую. Старая остаётся retired
для уже начатых партий. Устаревший ещё не запущенный план потребует пересборки.
Пустые паки и интересы сохраняются в редакторе, но отфильтровываются из лобби.

Сохранение, публикация и сброс используют один advisory lock и проверку
версии черновика и исходной ревизии. Конкурирующая вкладка получает 409;
её правки не перезаписывают новую базу. Операции пишутся в audit_log.
«Удалить черновик» возвращает редактор к опубликованной версии.

## Проверка

`apps/api/test/svoyak-admin.integration.test.ts` требует отдельную локальную БД
`svoyak_editor_test`; тест отказывается работать с другим именем или хостом.
Покрывает защиту API, конфликты, неизменность активного контента, атомарный
выпуск, запрет неиграбельной базы, безопасные URL, загрузку файла, редактирование
паков и отсутствие медиа ответа у игрока до раскрытия.

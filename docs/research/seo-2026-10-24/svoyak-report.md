# SEO страницы «Своя игра»: спрос и подготовленные изменения

Дата проверки: 24 октября 2026 года, Asia/Qyzylorda. Объект: `/games/svoyak`.

Страница соответствует игровому спросу «своя игра онлайн играть» и уточнению «с друзьями». Главный технический пробел в рабочей копии — публичная посадочная считалась служебным URL: runtime задавал `noindex`, Nginx добавлял `X-Robots-Tag: noindex`, отдельный HTML и запись sitemap отсутствовали. Подготовлена первоначальная SEO-публикация существующей игры по стандарту проекта. Это ещё не подтверждённый рост органики и не выполненный production-релиз.

## Wordstat

Источник — [Яндекс Wordstat](https://wordstat.yandex.ru/?region=all&view=table&words=%D1%81%D0%B2%D0%BE%D1%8F%20%D0%B8%D0%B3%D1%80%D0%B0%20%D0%BE%D0%BD%D0%BB%D0%B0%D0%B9%D0%BD), авторизованный интерфейс, «Топы запросов», все регионы, все три типа устройств. Доступный период: **08.09–07.10.2026**. На странице есть предупреждение о временной недоступности части данных. На дату проверки конец периода отстаёт на 17 дней; эти значения нельзя называть спросом за последние 30 дней до 24 октября.

| Выражение | Запросов за доступный период | Применение |
| --- | ---: | --- |
| `своя игра онлайн` | 38 920 | Общий кластер с большой долей просмотра телепередачи |
| `"!своя !игра !онлайн"` | 4 605 | Фиксированные слова, но смешанный интент |
| `своя игра онлайн играть` | 6 748 | Основной игровой кластер |
| `"!своя !игра !онлайн !играть"` | 708 | Подтверждение игрового интента с фиксированными словоформами |
| `своя игра с друзьями` | 4 717 | Широкое уточнение, большой разрыв с фиксированными словами |
| `"!своя !игра +с !друзьями"` | 8 | Узкая формулировка; не размер всего рынка |
| `своя игра онлайн с друзьями` | 481 | Прямое соответствие текущему продукту |
| `"!своя !игра !онлайн +с !друзьями"` | 32 | Узкий запрос с фиксированными словами |

Кавычки ограничивают число слов, `!` фиксирует словоформу, `+с` сохраняет предлог. Порядок слов не фиксировался оператором `[]`. Частотности пересекаются, не складываются и не означают число уникальных игроков. Сохранены общие числа над таблицей для каждого отдельно загруженного выражения: строки вложенной таблицы могут немного отличаться, например 476 против 481 для фразы с друзьями. Числа и ограничения доступны в [снимке](svoyak-wordstat.json).

В широкой таблице «своя игра онлайн» есть «смотреть онлайн» — 20 436 и «нтв своя игра онлайн» — 6 595. Поэтому широкий объём 38 920 не используется как оценка аудитории этой игры. Есть также запросы про паки и конструктор; текущий продукт собирает вопросы из готовой базы и не предлагает публичный редактор или загрузку своих паков. Эти обещания в посадочную не добавляются.

Остальные аналитические источники не исследовались по прямому ограничению пользователя «только анализ по Wordstat». Сравнений трафика 7/7 и 14/14, CTR или конверсий здесь нет. Wordstat показывает другой тип данных, из его частотности нельзя вывести результат SEO-изменений.

## Принятое оформление

- Title: «Своя игра онлайн — играть с друзьями в браузере | Сходится!».
- Description: «Играйте в „Свою игру“ онлайн с друзьями: 2–12 игроков, отдельный ведущий, темы и вопросы на очки. Клубный билет нужен ведущему, друзья входят бесплатно по коду».
- Первый экран и H1 «Своя игра» сохранены. Ниже добавлено описание формата, правил, доступа, FAQ, подбора вопросов и ссылки на остальные игры в существующем оформлении `game-landing`.
- Публичная страница получает canonical, index/follow, Open Graph, Twitter и JSON-LD по общему механизму. В разметке нет предложения «создание комнаты за 0 рублей»: ведущему нужен клуб, поэтому бесплатный Offer не добавлен.
- Страница включена в общий публичный реестр, HTML главной, навигацию и sitemap. Реестр ежедневных режимов и архив остаются прежними: «Своя игра» использует отдельную комнату.
- Сгенерированный HTML и runtime используют один компонент с одним источником SEO-контента. Для Nginx подготовлены публичный HTML-маршрут и миграция прежнего объединённого noindex-правила. Приватные `/svoyak/create`, `/svoyak/join/...`, `/svoyak/rooms/...` и результаты не индексируются.

Это устранение отсутствующего оформления существующей посадочной. Изменение не трактуется как CTR-эксперимент с одновременным переписыванием первого экрана; H1 и игровой первый экран сохранены. Метаданные, canonical и разметка других игр не переписываются. Контент базы вопросов, доступы и игровая механика не меняются.

## Проверка и выпуск

Локально выполнены:

- `npm run build` успешно: UI-copy, shell/design contracts, валидация библиотек, `tsc -b`, Vite и генерация 58 индексируемых HTML-страниц.
- Целевые `seo.test.ts` и `SeoContent.test.ts`: 32 проверки прошли. Включены публичная индексация «Своей игры», защита комнат и отсутствие бесплатного предложения создания комнаты в JSON-LD.
- Готовый `dist/seo/games/svoyak.html`: один H1, canonical, index/follow, Open Graph, Twitter, шесть FAQ, совпадение JSON-LD с runtime, ссылка с главной и одна запись sitemap. Результат сохранён в [сверке HTML](svoyak-validation.json).
- Исходные `GAME_SEO`, `HOME_SEO` и ежедневный реестр сравнены с копией до правок: совпадают.
- `bash -n` для Nginx patch и локальная проверка на старом и новом конфиге: публичный маршрут получает свой HTML без noindex, прежнее объединённое правило разделяется, повторный запуск не меняет результат. Проверка настоящим `nginx -t` остаётся частью будущего production-релиза.
- Браузер на `http://127.0.0.1:5180/games/svoyak`: реальный клиент и API, desktop и 390 px, FAQ открывается, canonical и метатеги соответствуют странице. При ширине 390 px scrollWidth 380 px, горизонтального переполнения нет. Консоль не показала warning/error. Мобильная эмуляция после проверки выключена. Партии и production-комнаты для проверки не создавались.
- `git diff --check` для изменённых в этой задаче файлов прошёл. Общая рабочая копия содержит прежние ошибки whitespace в `App.tsx`, `AdminApp.tsx` и `UI_DESIGN_GUIDELINES.md`; эти файлы в задаче не редактировались.

Снимки: [desktop](svoyak-desktop.png), [390 px](svoyak-mobile.png). Production не изменён. По `docs/SEO_GROWTH_EXECUTION_PLAN.md` выпуск требует отдельного разрешения владельца.

После разрешённого релиза нужны: HTTP 200 и отсутствие `X-Robots-Tag: noindex` у `/games/svoyak`; один H1, canonical и JSON-LD в исходном HTML; запись в sitemap; noindex у комнат; проверка desktop и 390 px. Дату и SHA выпуска следует записать отдельно.

Первые 7 завершённых дней после релиза — технический контроль обнаружения URL. Основная оценка — после полного 14-дневного окна с учётом задержки поисковых данных. Для новой индексируемой страницы дорелизный `noindex` не является сопоставимым CTR-baseline. Рост и конверсию нельзя объявлять доказанными до фактической проверки; дополнительные источники потребуют расширения текущей задачи.

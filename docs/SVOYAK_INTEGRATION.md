# Своя игра: серверная интеграция

## Запуск и маршруты

Обычный локальный стенд `npm run preview:review` на 5180 и основной сайт
используют один Fastify API `/api/v1/svoyak` и production PostgreSQL.
Редактор вопросов на 5188 остаётся отдельным редакторским инструментом;
для игры его запускать не нужно. Флаг сервера — `SVOYAK_ENABLED=true`.

| Экран | Путь |
| --- | --- |
| Общий выбор комнаты | `/lobby` |
| Карточка на главной | `/#home-games` |
| Титульный экран | `/games/svoyak` |
| Создание комнаты | `/svoyak/create` |
| Приглашение и вход | `/svoyak/join/:code` |
| Лобби и игра | `/svoyak/rooms/:code` |
| Результаты | `/svoyak/rooms/:code/result` |
| Старый визуальный стенд | `/shoditsa-svoyak.html?demo=board` |

Все новые экраны используют `ApplicationFrame`: штатные меню, аккаунт, правую
панель, её сворачивание и общий подвал. Путь имеет историю браузера и работает
при прямом открытии и перезагрузке. При отсутствии входа ссылка комнаты открывает
выбор имени и аватара. Подпись игрока — имя в комнате, без обязательной регистрации.

Общее «Лобби» доступно из основного меню и сквозного виджета «Собери компанию».
Оно направляет в существующие сценарии Викторины, Данеток и «Своей игры». Маршруты «Своей игры» открываются через общий application router
без отдельного HTML-входа. Старый HTML оставлен только для визуального демо.

Создание требует постоянного аккаунта с активным клубным билетом.
Fastify повторно проверяет сессию, блокировки и entitlement в БД.
Приглашённые игроки входят бесплатно, в том числе через штатную гостевую
сессию. Личная room-capability хранится в sessionStorage, связана с userId
и не попадает в приглашение. При превращении гостя в аккаунт эта привязка
переносится транзакционно вместе с прогрессом.

## Что работает

- Отдельный ведущий и 2–12 игроков. Каждый входит со своего токена; ведущий не
  участвует в счёте. В лобби можно менять имя и аватар, интересы и
  готовность. Ведущий может убрать участника или закрыть комнату.
- Настройки раундов, тем, времени и возраста. У взрослых по умолчанию разрешено
  18+. Юмор, абсурд, авторские формулировки и названия паков не переписываются.
- Общий пак по пожеланиям каждого, полные темы по пять вопросов, порядок
  сложности, воспроизводимый seed. Метаданные плана видны всем; сами вопросы
  и ключи не передаются в лобби.
- Старт после готовности всех и повторной проверки версий выбранных вопросов.
  Правка интересов, состава или настроек снимает план; правка своих интересов
  также снимает собственную готовность.
- Первый серверный buzz останавливает отсчёт. После ошибки — минус стоимость,
  15 секунд другим участникам и запрет повторного ответа того же игрока.
- Ведущий открывает ключ и принимает ответ; игроки получают ключ только после
  закрытия вопроса. Проигранный гонкой buzz возвращает конфликт, не меняя счёт.
- Следующий вопрос, переход между раундами, естественное окончание, досрочное
  завершение, таблица мест с ничьей, новая игра с прежним составом.
- Между играми этой комнаты исключаются показанные identity и совпадающие
  ответы. Результаты и события зачёта привязаны к версии вопроса и сохраняются
  отдельно от редакторской статистики.
- Перезагрузка и временная потеря соединения: токен хранится в `sessionStorage`,
  комната — на сервере; polling восстанавливает актуальное состояние.
- Темы сохраняются автоматически. Клиент объединяет быстрые клики и отправляет
  только один запрос за раз; следующий запрос несёт последний выбор. Черновик
  переживает перезагрузку, ошибки соединения запускают повтор с задержкой.
- Сервер автоматически пересобирает пак после изменения голосов, состава или
  настроек. Результат устаревшей сборки отбрасывается. Изменение имени, аватара
  или готовности сохраняется независимо от подбора. В лобби одна нижняя полоса:
  число вопросов, готовность, «Состав» и «Я готов» / «Начать игру».

## Источник вопросов

`QuestionBank` — заменяемый интерфейс в `apps/web/src/dev/svoyak/server/bank.ts`.
Локальный адаптер делает только GET-запросы к существующему редактору. Берёт
версии со статусом `approved`, пустым списком `blockers` и `media_policy=text_only`.
Не обходит проверки `workflow.playable`. Не вызывает `build`, `review`, `play`
или `presented` редактора и не меняет его БД.

Исходные `library.sqlite3`, `editorial.sqlite3`, SIQ и медиаредакция остаются
владением редактора. Первое чтение 200 ключей может занимать около 30 секунд.
Затем используется приватный кэш, связанный с состоянием файлов источника.
Перед стартом ключи проверяются заново по `content_hash` и допуску. Недоступность
редактора или отозванный вопрос не превращается в случайный запасной пак.

Выбор паков убран. Сервер собирает пул из всей допущенной базы, сохраняя
полные темы по пять вопросов. У каждого участника один базовый голос,
разделённый поровну между его интересами. Ведущий тоже может выбрать интересы;
если он ничего не выбрал, его голос не влияет на подбор. Игрок без выбора
распределяет голос поровну между доступными интересами.
Объём распределяется по суммарным весам с округлением до полных тем и учётом
наличия вопросов. Последние места защищают интересы ещё не представленных
участников. В плане сервер возвращает веса и фактическое число вопросов по
интересам. Устаревшие фильтры packIds игнорируются; старые планы лобби требуют
пересборки. Выбор тем виден сразу у всех участников, состав игры — в диалоге.
Отдельно исключаются совпадающие ответы, формулировки и известные связи дублей.
Если полных тем мало либо пожелания участника не представлены, возвращается
понятная ошибка с предложением расширить выбор. Неодобренные вопросы не подмешиваются.

## API v1

Контракт: `packages/contracts/src/svoyak.ts`. Клиент: `apps/web/src/features/svoyak/client.ts`.
Правила: `packages/game-core/src/svoyak/service.ts`. Fastify и PostgreSQL:
`apps/api/src/modules/svoyak/`.

| Запрос | Назначение |
| --- | --- |
| `GET /api/v1/svoyak/catalog` | Паки, интересы, доступность, ревизия; без ключей |
| `POST /api/v1/svoyak/rooms` | Создать комнату, получить личный токен ведущего |
| `POST /api/v1/svoyak/rooms/:code/join` | Войти, получить личный токен игрока |
| `GET /api/v1/svoyak/rooms/:code` | Состояние с персональным редактированием ключей |
| `POST /api/v1/svoyak/rooms/:code/commands` | Команда, `commandId`, авторизация Bearer |

Команды: `profile`, `preferences`, `settings`, `ready`, `prepare`, `start`, `choose`, `buzz`,
`reveal`, `judge`, `next`, `finish`, `rematch`, `kick`, `leave`.
Повтор `commandId` не удваивает счёт. Проверяются роль, стадия, время, допустимые
имена, аватары и параметры. Токены в приглашения не попадают; сервер сохраняет
только SHA256 токенов. JSON состояния игроков не содержит приватных ключей,
хешей авторизации или формулировок закрытых вопросов.

`preferences` сохраняет только интересы, `profile` — имя и аватар (старое поле
`preferences` в этой команде поддерживается для совместимости). `prepare`
сохранена для совместимости API; интерфейс её не вызывает. Поле `preparation`
возвращает `waiting`, `building`, `ready` или `error` с сообщением.
Подбор запускается с задержкой 350 мс после последнего изменения и сверяет
состав/интересы/настройки перед записью. Временная недоступность источника
повторяется через 10 секунд при опросе комнаты. Ошибка нехватки тем ждёт нового
выбора. После перезапуска сервера опрос возобновляет незавершённый подбор.

Примеры ошибок: `NOT_READY`, `NEED_PLAN`, `PLAN_STALE`, `ROOM_CHANGED`,
`INSUFFICIENT_QUESTIONS`, `HOST_ONLY`, `BUZZ_CLOSED`, `ROOM_NOT_FOUND`.

## Хранение и выпуск

Миграция `0056_svoyak_production` добавляет отдельные неизменяемые ревизии
контента, вопросы, комнаты, участников, события ответа, результаты и outbox.
Команды сохраняются транзакцией с блокировкой комнаты и проверкой revision.
На старте и перед открытием вопроса повторно проверяется допуск и хеш.
Комната восстанавливается после перезапуска процесса; TTL — семь дней.
Polling передаёт heartbeat, отсутствие ведущего обозначается в интерфейсе;
автоматической передачи роли ведущего нет.

Публичный выпуск `data/svoyak/release-v1.json` создан из существующего
редакторски одобренного текстового снимка по указанию владельца 23.10.2026.
В нём 337 одобренных вопросов (168 с отдельной правкой формулировки);
игровой подбор использует 162 вопроса в 25 полных темах, 13 интересов.
Неполные темы и неодобренные исходники не дополняют подбор.
Provenance сохраняет редакторский источник и его хеш; исходные разрешения
авторов не изменяются и не выдумываются. Библиотека не входит в web bundle.

`content-bootstrap-svoyak` по умолчанию выполняет dry run. Публикация:
`node apps/api/dist/content-bootstrap-svoyak.js --apply --activate --actor-id=<admin UUID>`.
Нужен существующий администратор; публикация протоколируется в audit_log.
Снятая ревизия не активируется повторно. CI выпускает API, миграцию, контент,
worker и web вместе; web-only deploy не является запуском этой игры.

Результат и событие outbox записываются один раз. QA-комната исключается из
outbox только по заголовку `x-shoditsa-qa: svoyak` авторизованного администратора.
Тестовые ответы не подменяют реальные данные редакторской калибровки.
Изображения, аудио и видео пока не входят в опубликованный текстовый режим.
